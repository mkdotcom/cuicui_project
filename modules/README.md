# modules

Optional cuicui modules go here. Clone the ones you need:

```
cd modules
git clone https://github.com/mkdotcom/cuicui_biometricAuth.git
```

| Module | What it does | Platforms |
|---|---|---|
| [cuicui_biometricAuth](https://github.com/mkdotcom/cuicui_biometricAuth) | Fingerprint / face authentication prompt | Android |
| [cuicui_wOpenGL](https://github.com/mkdotcom/cuicui_wOpenGL) | OpenGL ES view widget (experimental) | Android (manual loop), iOS, UWP |
| [cuicui_wMap](https://github.com/mkdotcom/cuicui_wMap) | Map widget (experimental) | Web (Google Maps), UWP (Bing Maps) |

Each module's README explains how to add it to each platform project.
How modules work: [MODULES.md](https://github.com/mkdotcom/cuicui_core/blob/main/docs/MODULES.md).
